## 🎯 Quick Start

### 1. Clone This Repository
```bash
git clone https://github.com/januarfonti/opencode-template-configured.git
cd opencode-template-configured
```

### 2. Copy to Your Project
```bash
# Copy the .opencode folder to your project
cp -r .opencode /path/to/your/project/
```

### 3. Start Using OpenCode
```bash
cd /path/to/your/project

# Start with an agent
opencode --agent openagent

# Or for Next.js projects
opencode --agent frontend-developer

# Or for Nuxt projects  
opencode --agent nuxt-developer
```
